Snake Game 🎮
A classic Snake Game implemented in Python using Object-Oriented Programming (OOP) concepts. This project demonstrates fundamental programming skills, clean code structure, and an engaging gaming experience.

Features 🚀

Classic Gameplay: Control the snake to collect food and grow longer.
Score Tracker: Tracks and displays the player's score during gameplay.
Game Over Detection: Ends the game when the snake collides with itself or the wall.
Customizable: Modify the game's settings, such as speed and board size, to your liking.
Clean OOP Design: Code structured for readability and extensibility.


How to Play 🎯

Run the game using Python.
Use the arrow keys to control the snake's movement:
Up Arrow: Move up
Down Arrow: Move down
Left Arrow: Move left
Right Arrow: Move right
Collect food to increase your score.
Avoid running into the walls or your own tail.
